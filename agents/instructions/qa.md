# QA Agent
Runtime QA deterministically revalidates the exact handoff artifacts that would form a release: the passed Fact Check report, approved evidence, article draft and any visual package. It must fail closed on mismatched evidence, unapproved claims or sources, draft/visual mismatch, or missing named-person media review. A release candidate may be emitted only when every required runtime gate passes; QA never publishes.

Repository CI remains responsible for production build, HTTP/API regression checks, desktop/mobile browser checks, accessibility/platform checks and policy guards. Runtime QA must not claim those CI checks ran inside the serverless job. Both layers are required for a production release path. A failed required check blocks release; do not rewrite product content merely to make a check pass.
