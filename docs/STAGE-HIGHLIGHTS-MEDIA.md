# Архивное видео и качественные обложки этапов (ноябрь 2026)

## Видео
Проверенные авторские ролики официального канала IBU/Biathlonworld доступны для двух этапов с проверенным `competitionKey`: Контиолахти 2026 и Хохфильцен 2025. Это нарезки прошлого сезона 2025/26, а не трансляции 2026/27. Никакие видео не скачиваются, не хранятся на Vercel/Supabase и не копируются в публичный архив. На сайте отображается собственный HTML-постер с официальной миниатюрой, при нажатии подключается YouTube privacy-enhanced iframe. До клика нет iframe, тяжёлого видеопотока и внешних медиаскриптов. Предусмотрена ссылка на исходное видео, если встраивание ограничено регионом/правообладателем.

Каталог связывает видео с точным ключом этапа. Автоматический поиск по названию, если он может подставить другую гонку или сезон, не выполняется. Остальные этапы ждут подтверждённой официальной записи.

## Фотографии
Для двух биатлонных этапов подобраны архивные высокоразрешённые фотографии места соревнований из Wikimedia Commons с указанными фотографом, датой и лицензией CC BY-SA. Они не представляются кадрами текущего сезона. Сайт использует оптимизацию Next Image (адаптивные размеры, lazy loading) и возвращается к графической обложке при ошибке изображения. Условия атрибуции обязательны.

Неизвестный правообладатель, случайные фотографии с IBU/FIS/СМИ, отсутствие лицензии либо несоответствие арене блокируют публикацию. Для остальных этапов остаётся ранее проверенный графический фон. Локальные загруженные фотографии допускаются только через существующий approvedStagePhoto guard.

## Редакционная автоматика
Official story intake выполняется по расписанию, но это только сбор кандидатов, не автопубликация. ИИ-редактор получает только проверенные факты; материал должен пройти fact check и QA. Не включать автоматического publisher без действующих прав, проверки фактов, устойчивого хранения и тестов.
