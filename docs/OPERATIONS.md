## Обнаруженный сбой источника

GitHub Actions run 37021133963, job 110884199550: существующий `scripts/test-parsers.mjs` получил 0 строк там, где ожидал минимум 20. Это живой сетевой контракт с исторической страницей FIS, а не автономный unit-тест. Причина пока не установлена: HTTP-статус, антибот-ответ или несовпадение HTML требуют отдельной диагностики. Нельзя утверждать, что parser исправлен, просто убрав проверку количества строк.

Автономные тесты приложения отделены от сетевой проверки. Исходный scheduled workflow Parser Regression Check сохранён. HTTP-ошибка, неожиданный документ и ошибка парсера должны различаться. Не обходить ограничения источника. Не превращать ошибки в пустой успешный импорт и не удалять данные из базы из-за пустого ответа.

Скрипт FIS раньше по умолчанию использовал результат сезона 2026; для сезона 2026/27 требуется явный URL/идентификатор и проверка сезона. FLGR-скрипт проверял размеры HTML и пытался записать source_snapshot в поле item_kind, отсутствующее в текущей таблице intelligence_items. Поэтому задачи discovery должны оставаться без публикационных прав до исправления контрактов.

## Выпуск

Перед merge: тесты доменных правил и парсеров на автономных фикстурах, TypeScript/production build, проверка страниц и заголовков, отсутствие демонстрационных данных, проверка ссылок. Сетевой источник оценивается отдельно и его сбой не скрывается зелёной сборкой UI. Зафиксировать package-lock из реально разрешённых зависимостей; не хранить только плавающие версии. CI работает без production service-role ключа.

Vercel connector get_project возвращал ошибку схемы idOrName, список проектов показывал только другой проект; нельзя развёртывать в TopRunners по умолчанию. GitHub показывает независимые статусы Vercel. Основной домен сначала подтвердить; до этого не обещать индексацию. Пустой SITE_URL и отсутствие платформенного production origin приводят к noindex.

## Секреты и откат

Реальные CRON_SECRET, SUPABASE_SERVICE_ROLE_KEY и будущие бот-токены задаются в менеджере секретов, не в чате/публичных файлах. CRON_SECRET должен содержать минимум 32 случайных символа. Отсутствие секрета приводит к 503, неверный — к 401 до запросов источников. Базовый CSP пока допускает inline bootstrap Next.js; строгая nonce-политика требует отдельной совместимой работы.

Откат UI — предыдущий успешный deployment/commit. Не откатывать RLS к публичному доступу черновиков. При ошибке изменения прав использовать минимальную корректирующую миграцию и повторить отрицательные тесты. Полная история старых миграций ещё должна быть синхронизирована с репозиторием перед автоматическим db push.
