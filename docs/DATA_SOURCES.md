# Winter Sports Hub — source hierarchy

## Tier 5 — source of truth
- IBU / Biathlonworld Datacenter: international biathlon calendar, results, standings, athletes.
- FIS Cross-Country: international calendar, results, athlete IDs and official documents.
- Russian Biathlon Union (СБР): Russian calendar, official documents, rankings and competition pages.
- FLGR Results: Russian cross-country results and athlete registry with RUS/FIS identifiers.

## Tier 4 — official context
Organizers, national teams, athlete public accounts, official VK / YouTube / Instagram accounts.

## Tier 3 — established media
Interviews and reporting. Useful for context; never silently overwrites an official result or schedule.

## Tier 2 — public communities
Useful as discovery signals. Claims require corroboration.

## Tier 1 — unverified
Stored only as a lead; excluded from automated factual articles.

Every stored item should preserve source URL, timestamp and reliability. Predictions must preserve the evidence snapshot available before the race.
