## Reader changes
Native GET search on /media searches only verified published title/dek/body plus an explicit spelling-alias registry. Russian е/ё and Latin diacritics/ligatures normalized; Klaebo/Klæbo/Клебо/Клэбо resolve as documented aliases, not generative fuzzy claims. Every query word must match. Maximum120UTF16codeunits/12terms; duplicate/oversized/meaningless queries produce a visible error, not an implicit unfiltered list. Search input is never interpolated into SQL or a user-created regex. Sorts: relevance with title/name weighting, newest, shortest estimated read. Tie order is deterministic. Existing sport/type/athlete filters all still apply. Empty combinations remain empty; remove-one-condition links preserve other filters and use same-origin allowlisted keys only.

Form and server search work without JavaScript. No Algolia/LLM/search paid service, hidden query POST, profile or tracking database introduced. Search is not anonymous: GETquery is present in URL/history and may be in hosting request logs, disclosed in UI. Do not type private information. All query/filter URLs remain noindex and canonicalize to /media under existing site-origin rules; no new production domain or legal gate is invented. Primary references consulted: https://nextjs.org/docs/app/api-reference/functions/generate-metadata and https://www.w3.org/WAI/WCAG21/Understanding/status-messages .

The library header is shorter; large explanatory data blocks move below article cards. Tables/data labs and guides retain real links and accessible labels. Russian material counts inflect correctly. No athlete photo generation, new video payloads or third-party embed.

## Item isolation, still fail-closed for unreviewed content
Previously one mismatched manifest body made the entire editorial feed unavailable. Now each known article must independently pass existing body/title/dek/source marker/publication checks, numericID, approved editorial byline and valid update timestamp. Mismatch is withheld, not repaired/generated, while unrelated valid stories remain available with a partial-catalog notice. Duplicate publishedslug withholds every duplicate. Unknown nonmanifest rows are never searchable. A direct request for a withheldknownslug still fails as a temporaryservererror, not soft404 or unreviewed fallback. Sitemap refuses partial editorial data rather than pretending the missingURLwas deleted. Database read failure or100rowlimit still stops the full query. No loosening of RLS and no writes to published text.

Synthetic tests must cover one bad/one good row, future/draft/byline/date mismatches and duplicates. No fault injection into productionDB. Existing source/privacy/clock/FLGRreview/upload/recovery boundaries remain open unless independently resolved; no claim that a search release certifies them. Final exacthead CI, actual snapshots/screenshots and deployment receipt belong in PR after execution.
